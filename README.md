## The outcome

Turn discovery notes into a professional, on-brand proposal with a clear next step. This skill covers meeting notes, structured sections, five proposal styles, six color themes, and custom templates.

## What you get

A polished HTML proposal that reflects the real conversation and is ready for human review.

## Quick start

1. Install the ClawHub skill: `ai-proposal-generator`
2. Run `/ai-proposal-generator`
3. Provide the discovery notes, client situation, scope, constraints, proof, and approved commercial terms. Never let the tool invent pricing or promises.
4. Review the output before publishing, sending, or changing live systems.

## A useful first prompt

```text
Use /ai-proposal-generator with me. First ask only for the information you need to produce a reliable result. Do not invent missing facts, claims, prices, owners, or deadlines. Show me the draft before anything is published or sent.
```
